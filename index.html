How BFS Works

  1. BFS starts from the entrance.
  2. It visits neighbouring cells level by level — all cells one step away first, then two steps away, and so on.
  3. A queue controls the order of exploration (first in, first out).
  4. A visited set prevents the same cell from being explored twice.
  5. Parent references remember where each cell was reached from, so the final route can be traced back.
  6. The first suitable table found is the nearest one, because BFS explores in order of distance — so it is recommended.

Complexity: Time O(V + E)  |  Space O(V), where V = number of cells and E = number of connections between neighbouring cells. Every move costs the same (1 step), which is why BFS finds the shortest route.
